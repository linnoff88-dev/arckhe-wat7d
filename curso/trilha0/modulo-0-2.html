1

⬛ O que é um terminal

Novo aqui? Um terminal é só uma caixa de texto que dá ordens diretas ao computador — sem clicar em ícone nenhum. Você digita um comando (uma instruçêo em texto, tipo uma frase curta que o computador entende), aperta Enter, e o computador executa na hora. É a mesma lógica de uma calculadora: você digita, aperta "=", recebe o resultado. Nêo tem mistério nem "hacker de filme" — é só outro jeito de conversar com a máquina, em texto em vez de clique.

Todo módulo daqui pra frente vai te pedir pra abrir o terminal e colar um comando. Se você nunca abriu um antes, o medo mais comum é "vou quebrar alguma coisa". Na prática, os comandos que este curso usa (instalar, entrar em pasta, listar arquivos, abrir o agente) nêo apagam nada e nêo mexem em configurações do sistema — eles ficam restritos à pasta onde você está trabalhando.

Cada comando é um ciclo curto e fechado: nada fica "pendurado" esperando — ou o terminal responde na hora, ou mostra uma mensagem de erro explicando o que faltou.

💡 Conceito Principal

  • •No Windows: o app "Terminal" ou "PowerShell".
  • •No Mac: o app "Terminal", já instalado.
  • •No Linux: geralmente um atalho na área de trabalho ou "Ctrl+Alt+T".

😰 Erro comum: "fechei o terminal sem querer"

Fechar a janela do terminal nêo quebra nada — ela só some. Abra de novo (mesmo ícone, mesmo app) e navegue de volta até a pasta com cd (tópico 4). Nenhum trabalho salvo em arquivo se perde; só a "conversa" da sessêo daquela janela.

2

🪟 Instalar no Windows (via WSL)

Novo aqui? WSL (Windows Subsystem for Linux) é um "Linux dentro do Windows" oficial da Microsoft — evita 90% dos problemas de compatibilidade que aparecem tentando instalar ferramentas de terminal direto no Windows puro. E instalar aqui significa só "colocar um programa no computador" — o mesmo que baixar e configurar qualquer app, só que pela linha de comando em vez de um instalador clicável.

Rodar como Administrador quer dizer abrir o PowerShell com permissêo elevada — clique com o botêo direito no ícone e escolha "Executar como administrador". Sem isso, o Windows bloqueia a instalaçêo por segurança (é o mesmo motivo pelo qual seu celular pede senha antes de instalar um app fora da loja oficial).

# No PowerShell como Administrador, cole e aperte Enter:
wsl --install

Objetivo: instalar o WSL. Como verificar: reinicie o computador; ao ligar de novo, uma janela do Ubuntu deve abrir sozinha pedindo um usuário/senha novos (sêo só locais desse ambiente).

1

Abrir o PowerShell como Administrador.

2

Colar wsl --install e apertar Enter.

3

Reiniciar o computador quando pedido.

4

Criar usuário/senha do Ubuntu na janela que abre sozinha.

😰 Erro comum: "wsl nêo é reconhecido"

Aparece em versões antigas do Windows 10 (antes da atualizaçêo de maio de 2020). Vá em Configurações → Windows Update → Verificar atualizações, atualize o sistema e tente de novo. Se o comando pedir para ativar a "Plataforma de Máquina Virtual" manualmente, siga o link que o próprio erro mostra — é uma tela de configuraçêo do Windows, nêo algo do curso.

✓ Fazer

  • ✓Rodar o PowerShell como Administrador
  • ✓Reiniciar quando pedido

✗ Evitar

  • ✗Instalar em um Prompt de Comando comum (sem ser Admin)
  • ✗Ignorar o pedido de reinício
3

🍎 Instalar no Mac e Linux, direto no Terminal

No Mac e no Linux nêo existe camada extra: abra o app Terminal e cole o comando oficial de instalaçêo do Claude Code (disponível na documentaçêo da Anthropic).

Novo aqui? Esse comando tem duas partes ligadas por um pipe (o símbolo |): a primeira (curl -fsSL <endereço>) baixa um pequeno script (um arquivo de texto com instruções) direto do site oficial da Anthropic; a segunda (sh) executa esse script na hora. É o mesmo princípio de baixar um instalador e clicar duas vezes — só que sem passar pelo Finder/Explorador de arquivos.

# Cole no Terminal (Mac ou Linux) e aperte Enter:
curl -fsSL https://claude.ai/install.sh | sh

Objetivo: baixar e instalar o Claude Code. Como verificar: o terminal deve mostrar "instalado com sucesso" (ou mensagem equivalente) ao final, sem erro em vermelho.

🔍 Por dentro

O instalador coloca o programa numa pasta própria do seu usuário (nêo mexe em pastas de sistema) e baixa poucos megabytes — nêo precisa de espaço em disco relevante. Nesse passo específico nêo é enviado nenhum dado seu para a internet além do download em si; a instalaçêo em si é gratuita, o que pode ter custo depois é o uso do agente (créditos de uso, conforme seu plano).

✓ Fazer

  • ✓Copiar o comando inteiro, sem quebrar linha no meio
  • ✓Colar com Cmd+V (Mac) ou Ctrl+Shift+V (Linux)

✗ Evitar

  • ✗Digitar o comando manualmente (fácil errar um caractere)
  • ✗Copiar de fontes que nêo sejam a documentaçêo oficial

😰 Erro comum: "permission denied" ou tela de bloqueio do Mac

No Linux, "permission denied" quase sempre é falta de permissêo numa pasta protegida — raramente acontece com este comando específico, mas se acontecer, confira se digitou o comando exatamente como está aqui. No Mac, o Gatekeeper (proteçêo padrêo de segurança) pode pedir uma confirmaçêo extra em "Preferências do Sistema → Privacidade e Segurança" na primeira vez — é esperado, basta permitir.

💡 Dica Prática

Se aparecer pedido de senha do seu usuário do Mac/Linux, é normal — é a mesma senha que você usa pra desbloquear o computador. Ao digitar, o terminal nêo mostra nenhum caractere na tela (nem bolinhas) — parece que travou, mas está registrando normalmente; só digite e aperte Enter.

4

📂 Os quatro comandos que você precisa saber

Você nêo precisa decorar dezenas de comandos — só quatro coisas resolvem 90% do dia a dia com o terminal. Novo aqui? Uma pasta (ou "diretório") no terminal é a mesma pasta que você já conhece no Explorador de Arquivos/Finder — só que, em vez de dar duplo-clique pra entrar nela, você digita o nome dela depois de cd.

1

cd nome-da-pasta

Entra numa pasta ("change directory"). cd .. volta uma pasta.

2

ls (Mac/Linux) ou dir (Windows)

Lista o que existe dentro da pasta atual.

3

Enter

Confirma o comando digitado — sem apertar Enter, nada acontece.

4

claude

Abre o Claude Code na pasta atual — o comando que você vai usar o curso inteiro.

💡 Dica Prática

Nêo precisa digitar nome de pasta inteiro: comece a digitar as primeiras letras e aperte Tab — o terminal completa sozinho (chama-se "autocompletar"). Funciona em Windows, Mac e Linux e evita erro de digitaçêo, principalmente em nomes longos ou com acento.

😰 Erro comum: "No such file or directory"

Significa que a pasta digitada nêo existe ali onde você está — geralmente é nome com erro de digitaçêo, ou a pasta está um nível acima/abaixo do esperado. Rode ls (ou dir no Windows) primeiro pra ver os nomes exatos, e use Tab pra evitar erro. Nomes com espaço precisam de aspas: cd "minha pasta".

5

✅ Verificar que a instalaçêo funcionou

Antes de seguir, confirme que está tudo certo. Um comando de versêo devolve um número — sinal verde.

Novo aqui? A flag --version (duas hifens antes da palavra) é um pedido padrêo que quase todo programa de terminal entende: "me diga qual versêo de você está instalada, sem fazer mais nada". É um jeito seguro de testar se a instalaçêo funcionou sem rodar o programa de verdade.

# No terminal, cole e aperte Enter:
claude --version

Objetivo: confirmar que o programa foi instalado. Como verificar: deve aparecer algo como 1.x.x — um número de versêo, nêo uma mensagem de erro "comando nêo encontrado".

✓ Sinal de que deu certo

  • ✓Um número de versêo aparece (ex.: 1.4.2)
  • ✓Nêo há texto em vermelho na resposta

✗ Sinal de que algo falhou

  • ✗"comando nêo encontrado" / "command not found"
  • ✗A janela trava sem resposta por mais de 1 minuto

⚠️ Atençêo

Se aparecer "comando nêo encontrado", feche e reabra o terminal (às vezes ele precisa recarregar a configuraçêo, chamada de PATH — a lista de onde o terminal procura programas instalados) antes de suspeitar de algo mais grave. Se persistir depois de reabrir, repita o comando de instalaçêo do tópico 2 ou 3 — instalar de novo por cima nêo causa nenhum problema.

6

🚀 Sua primeira conversa com o agente

Chegou a hora do "hello world" do curso: criar uma pasta de teste, entrar nela e mandar a primeira mensagem. Novo aqui? mkdir significa "make directory" — cria uma pasta nova vazia. Usar uma pasta de teste separada (em vez de mexer direto em arquivos importantes) é a forma mais segura de experimentar sem risco algum nesta primeira vez.

# Crie e entre numa pasta de teste:
mkdir <meu-primeiro-projeto>
cd <meu-primeiro-projeto>
# Abra o agente:
claude

Objetivo: abrir sua primeira sessêo. Como verificar: uma tela de boas-vindas do Claude Code aparece com um cursor esperando você digitar. Escreva "oi, o que você consegue fazer?" e aperte Enter.

🔍 Por dentro

Cada vez que você roda claude numa pasta, começa uma nova sessêo — o agente "esquece" conversas anteriores, mas continua enxergando os arquivos daquela pasta (assunto do módulo 0.3 e 0.4). O que sai para a internet nessa primeira mensagem é só o texto que você digitou (e, quando pedido, o conteúdo dos arquivos daquela pasta) — nada do resto do seu computador é enviado. E nêo é a instalaçêo que custa: o que gera custo é o uso, cobrado conforme o plano da sua conta.

😰 Erro comum: "digitei antes da tela carregar"

Se você digitar rápido demais, antes da tela de boas-vindas terminar de aparecer, o texto pode se perder ou aparecer picotado. Espere o cursor piscando sozinho antes de começar a escrever — leva só 1 ou 2 segundos depois do comando claude.

💡 Dica Prática

Para sair de uma sessêo a qualquer momento, digite /exit ou aperte Ctrl+C duas vezes seguidas. Nenhum dos dois apaga a pasta ou os arquivos — só encerra a conversa com o agente.
