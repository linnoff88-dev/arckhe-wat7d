🪜 Carga progresiva en 3 niveles

1

🧠 El problema: la memoria de trabajo es limitada

¿Eres nuevo aquí? Contexto (o ventana de contexto) es la memoria de trabajo del agente: todo lo que puede "ver" a la vez mientras piensa y decide: tu conversación, los archivos abiertos y cualquier texto cargado en la sesión. Es finita. No infinita ni elástica: es un espacio limitado que hay que usar con cuidado, igual que en una mesa de trabajo solo caben cierta cantidad de papeles abiertos al mismo tiempo.

Si se leyera cada skill instalada entera, desde el primer hasta el último carácter, cada vez que el agente pensara en cualquier cosa, el problema sería evidente: con 20 skills instaladas, buena parte del contexto ya se habría agotado antes de que terminaras de escribir tu pedido. El agente sería más lento, más caro y más confuso, lleno de instrucciones de skills que ni siquiera eran relevantes para la tarea actual.

⚠️ Atención

Este escenario — cargarlo todo siempre — es exactamente lo que evita el formato de skill. La solución no es «tener pocas skills». Es cargar cada una en la medida adecuada, en el momento adecuado. De eso trata todo el módulo.

🔍 Por dentro

Piensa en una biblioteca enorme. Si cada vez que necesitaras un libro específico pusieran toda la biblioteca sobre tu mesa, nunca encontrarías nada. La forma en que funciona de verdad: un catálogo breve (el fichero de la entrada) te ayuda a encontrar el libro correcto, y solo ese el libro sale de la estantería.

2

1️⃣ Nivel 1 — el índice, siempre cargado

O Nivel 1 es solo el name e a description del front matter (que viste en el módulo 3.1): unos 100 tokens por skill. Es muy barato, y justamente eso es lo que el agente revisa para decidir, con cada nueva solicitud, si alguna skill instalada sirve para la tarea actual. Es como el índice de un libro: una línea por capítulo, suficiente para saber si ese capítulo es el que buscas, sin leerlo entero para averiguarlo.

Leyenda: el costo crece desde adentro hacia afuera: el centro (Nivel 1) es diminuto y siempre está presente; cada anillo exterior entra en escena solo si el anterior decidió que era necesario.

💡 Consejo práctico

Es por eso que el costo de tener instalar una skill casi no cuesta nada: incluso con 20 instaladas, el agente solo revisa 20 fichas breves. El costo real solo aparece cuando se usa una de ellas.

3

2️⃣ Nivel 2 — el capítulo, solo cuando se activa

O Nivel 2 entra en escena solo cuando la skill se activa de verdad, es decir, cuando la description del Nivel 1 coincide con tu pedido. Entonces sí, el agente carga el skill.md entero: el cuerpo con el paso a paso completo, de entre 1.000 y 2.000 tokens. Es el capítulo del libro que de hecho elegiste leer, después de mirar el índice y decidir que era ese.

A

Inicio de la sesión

Todas las descripciones de Nivel 1 ya están disponibles para que el agente las compare con cualquier solicitud.

B

Haces una solicitud que coincide con una de ellas

En ese preciso instante —ni antes ni «por si acaso»—, el Nivel 2 de esa skill específica entra en el contexto.

C

Las otras 19 skills siguen solo en el Nivel 1

No costaron nada extra: siguen siendo solo fichas, listas por si aparece una solicitud que encaje con ellas.

🔍 Por dentro

Es el mismo principio de lectura bajo demanda que ya apareció en el módulo 2.4 con el patrón cheat sheet: una instrucción breve que solo trae más detalles cuando hace falta. Las skills aplican este principio de forma estandarizada e integrada en su propio formato.

4

3️⃣ Nivel 3 — el apéndice, a pedido

O Nivel 3 es lo que queda en las carpetas references/ e scripts/ del módulo 3.1, y solo se lee si el paso a paso del Nivel 2 lo indica explícitamente ("si necesitas el detalle X, lee el archivo Y"). Es el apéndice técnico del libro: la mayoría de los lectores nunca llega allí, pero cuando alguien lo necesita, está justo donde debería estar.

El tamaño del Nivel 3 es variable: puede ser un archivo de 200 tokens o una referencia de 5.000. Pero eso no importa para el costo diario, porque en la gran mayoría de las ejecuciones nunca se abre.

✓ skill.md conciso

  • ✓El cuerpo con los pasos esenciales cabe en una pantalla
  • ✓Deja la tabla de códigos, los ejemplos extensos y los casos poco comunes para references/
  • ✓El costo del Nivel 2 siempre se mantiene cerca de 1-2 mil tokens

✗ skill.md gigante

  • ✗Pega todo en el cuerpo: tabla, ejemplos, casos poco comunes, todo junto
  • ✗Toda ejecución carga todo el material, incluso cuando no se usa el 90%
  • ✗El Nivel 2 se convierte, en la práctica, en un Nivel 3 disfrazado; pierde la ventaja de la carga por capas
5

🚀 Por qué tener 20 skills instaladas no ralentiza al agente

Junta los tres niveles y la respuesta a la pregunta que abrió este módulo queda clara: el costo de tener instalar una skill casi no cuesta nada (solo el Nivel 1, ~100 tokens cada una). El costo de usar una skill es proporcional solo a lo que realmente se activó: Nivel 2 siempre, Nivel 3 rara vez. Tener 20 skills instaladas y usar solo una termina costando casi lo mismo que tener instalada solo esa, más un puñado de fichas de índice de las otras 19.

🎯 Concepto principal

  • •Tener una skill instalada ≠ pagar su costo siempre. Eso ya se resuelve en el Nivel 1.
  • •Usar una skill cuesta en proporción a lo que realmente utilizó: Nivel 2 casi siempre, Nivel 3 rara vez.
  • •Es seguro instalar muchas skills específicas en lugar de unas pocas skills genéricas enormes.

💡 Consejo práctico

No dudes en tener una skill separada para cada proceso pequeño de tu rutina, en vez de una skill «todoterreno». Las skills específicas con descriptions precisas se activan mejor y mantienen corto el Nivel 2: el costo de tener una más instalada es irrelevante.

6

✍️ Escribir una description que active correctamente el Nivel 1

Como el Nivel 1 es el único filtro que decide si se carga o no el Nivel 2, la description debe cumplir dos funciones al mismo tiempo: decir lo que la skill hace y cuándo usarla, con palabras parecidas a las que usas cuando pides la tarea en la práctica. El módulo 3.4 profundiza en este tema; aquí queda el ejemplo funcional mínimo.

Objetivo: front matter que se activa correctamente en el Nivel 1
---
name: <nome-da-sua-skill>
description: <o que ela faz>, use quando o usuário pedir
  "<frase 1 que você diria>", "<frase 2>" ou "<frase 3>".
---
Cómo verificar: solicita la tarea usando exactamente una de las frases de la description y comprueba si el agente la reconoció y mencionó el nombre de la skill antes de actuar. Si duda o la ignora, probablemente la description sea demasiado genérica.

⚠️ Atención

Una descripción demasiado vaga («ayuda con informes») compite mal con otras skills parecidas y hace más compleja la decisión del Nivel 1 sin necesidad. Una descripción demasiado específica («genera un informe de ventas de octubre de 2026») solo se activa ese mes. El equilibrio adecuado es el tema del módulo 3.4.

Ejercicio mental: si tienes 20 skills instaladas y ninguna se usa en esta sesión, ¿cuántos tokens cuesta aproximadamente?

✅ Resumen del módulo

✓
Nivel 1: siempre cargada, ~100 tokens, decide SI la skill es adecuada.
✓
Nivel 2: solo cuando se activa, 1-2 mil tokens, el paso a paso completo.
✓
Nivel 3: solo bajo demanda, de tamaño variable, se lee solo si el Nivel 2 lo indica.
✓
Costo: tenerlo es casi gratis; usarlo cuesta en proporción a lo que se activa.

📝 Ejercicio

Elige una skill que ya uses o una que quieras crear. Escribe su description en una frase, con el formato del bloque copy-run anterior. Después, pruébala pidiendo la tarea exactamente con una de las frases que escribiste y comprueba si se activó.
