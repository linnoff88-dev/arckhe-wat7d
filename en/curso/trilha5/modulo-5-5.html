MODULE 5.5

🖼️ Visual reference and rebranding

Showing the agent a reference breaks you out of module 5.1’s “generic website” faster than any prompt. But references come with a rule: learn from the layout, never copy the brand. This module teaches the filter that separates “drawing inspiration” from “cloning”—and how to give the right instructions so you end up with an identity of your own.

1

📖 The home decor magazine, not the neighbor’s house plans

New here? Visual reference it’s showing the agent an existing website, layout, or image so it can understand the style you want—not the content, the style: where the blocks go, the size of the headings, the overall feel (understated, colorful, dense, airy). It's what an architect does when flipping through a home decor magazine before designing your house: they won't copy the cover house brick by brick — they gather ideas like "I like this living room layout," "I like this kind of lighting," and use them to design a new house of your own.

The agent sees a reference the same way it sees anything else in this track: through screenshot (a screenshot of the screen — module 5.3) or through a link it opens and analyzes. The difference between module 5.5 and 5.3 is what you do with what it learned: in 5.3 it compared its OWN work against the design. Here it looks at someone else's work someone else to learn a layout pattern — and this is a distinction that needs to be clear from the start, because it's easy to slip from "learning from" to "copying from."

Caption: the reference comes in from the left as a layout source only; the “brand filter” in the middle systematically changes the color, font, logo, and tone; what comes out on the right has the same arrangement but a new identity.

💡 Main Concept

Visual reference = layout raw material. What you build afterward is yours — it always goes through the brand filter before publishing.

  • •An architect looks at 20 magazines and doesn’t build any of those 20 houses—they build the 21st.
  • •Your reference can be a competitor, a site you admire, or a portfolio example—as long as the final result doesn’t look like the same site.

2

⚖️ Inspiration × cloning: the line you must not cross

This is the explicit rule of Track 5, and it’s serious: reference is for learn and then build your own website with your own brand — never to copy someone else's entire website, including another company's design, text, and images. Copying a real brand's visual identity (its exact colors, logo, text, photos) may infringe intellectual property rights and, in practice, mislead visitors into thinking your site belongs to another company.

The good news: it’s easy to draw the line between the two once you know what to look for. Layout (section layout: large hero, then 3 cards, then testimonials), composition type (image on the left / text on the right) and navigation structure are widely used design patterns — no one "owns" the idea of having a menu at the top. But brand colors (the exact color palette that identifies that company), logo, original texts e photos/illustrations protected items are assets specific to that brand — those must not be touched.

✓ Get inspired (OK)

  • ✓Copy the layout: hero + 3 sections + testimonials + footer
  • ✓Using the same type of composition (large background image, centered text)
  • ✓Adopt the visual "feel": minimal, dense, colorful, corporate
  • ✓Take the idea behind a feature (carousel, expandable FAQ) without copying its protected source code

✗ Clone (not OK)

  • ✗Using another company's exact brand colors (its specific hex value)
  • ✗Copy the logo, even if “adapted”
  • ✗Paste her original text (taglines, product descriptions)
  • ✗Download and reuse the protected photos/illustrations from the reference site

⚠️ Attention

If, when the site is finished, someone familiar with the reference says, “This is a copy of [company name],” you’ve crossed the line—even if no text or image was copied literally. The test is simple: the result needs its own identity, not a borrowed one.

3

🎨 What rebranding looks like in practice for an agent

New here? Rebranding, here, is the process of taking a reference layout and systematically replacing everything that identifies the original brand with your own: colors, typography, logo, and voice. It’s not “making do”—it’s a complete, deliberate replacement, point by point, until no trace of someone else’s identity remains.

New here? Color palette is the set of colors that represents your brand (usually 1 main color + 1–2 supporting colors + neutrals). Each color has a hex — a 6-character code like #0d9488 that identifies that exact shade, unambiguously. This is the code you give the agent—“blue” is vague, #2563eb it’s exact.

1

Color out, hex in

Every element that used the reference color (buttons, links, backgrounds, icons) switches to your palette, color by color.

2

Typography switches families

The title and body text use your font — even if the "visual weight" (large, bold headings and understated text) stays similar.

3

Replace it with the logo and proper name

Where the reference had its logo, yours goes (created in module 5.6, “Brand folder”).

4

Texts are written from scratch, in your tone

Don't translate or paraphrase the reference text — every sentence on your site is written with your business and your way of speaking in mind.

4

📎 Giving the agent the right reference

The reference reaches the agent in two ways: a link that it accesses and analyzes (using the same browser tools as module 5.3), or a screenshot that you attach directly to the conversation. A screenshot is more reliable when the reference site blocks automated access, or when you want to show just a specific section (the hero, not the whole site).

Caption: the ladder has 3 steps — choose, point out what to copy, explicitly point out what not to copy. Skipping step 3 is the most common mistake (see topic 6).

🔍 Inside

  • A good reference: a site for the same TYPE of business or goal as yours — a service landing page, portfolio, or store — it doesn’t need to be in the exact same niche.
  • Scope instruction: always say which PART to look at (“the header and the pricing section”), not “copy the entire site” — this reduces the chance that the agent pulls in brand details too.
5

📝 Brand guidelines: the prompt that makes rebranding work

New here? Brand voice it’s how your company “speaks”—formal or casual, technical or simple, serious or humorous. Just as the palette needs exact hex codes, the voice needs a concrete description (“direct and jargon-free, as if explaining it to a friend” is better than “professional”).

A complete rebranding prompt has 4 ingredients: the reference (with scope), the hex palette, the brand name/logo, and the tone of voice. Leave one out, and the agent fills the gap with the module 5.1 "generic"—or worse, with a trait from the reference that should have been changed.

How to verify: compare the result with the reference — if someone who doesn't know either site looks at yours and doesn't recognize the original brand, the rebranding worked. Also check that every hex code in the palette was actually applied (not just the main color).

💡 Practical Tip

Save this “palette + name + tone” block — it’s the skeleton of the “brand folder” you’ll formalize in module 5.6, so you don’t have to rewrite all of this for every new project.

6

🚫 Common mistakes and final checklist

The two mistakes that come up most often when someone starts using references: first, let the agent copy text and images — ask only to "make it look like this site" without explicitly saying that text/images/logo shouldn't be copied, and the agent (trying to follow your request faithfully) reuses what it found. Second, forget to change the palette — ask for a rebrand but don't provide the hex codes, so the agent keeps colors similar to the reference "because they worked with the layout."

✓ Well-crafted prompt

  • ✓Says "layout only" and lists exactly what to copy
  • ✓Pass exact hex codes for the palette, not vague color names
  • ✓Asks for original copy for your business
  • ✓Asks for visual confirmation by comparing the result with the reference

✗ Risky prompt

  • ✗"Make it just like this website" with no caveats
  • ✗Without a hex palette, the agent guesses the colors
  • ✗Without asking for original text, the agent reuses phrases from the reference
  • ✗Without a final review comparing the two side by side

✅ Checklist before publishing something inspired by a reference

  • ☐ The result uses YOUR palette, with verified hex codes — none of the colors are "similar" to the reference.
  • ☐ The logo and name are 100% yours (created or replaced, not taken from the reference).
  • ☐ All text was written for your business — no sentence is a translation/paraphrase of the reference.
  • ☐ No images/photos/illustrations from the reference were reused.
  • ☐ You reviewed them side by side and would say out loud: "this is mine, inspired by it, not a copy".
