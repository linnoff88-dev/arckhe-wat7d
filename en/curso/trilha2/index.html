TRACK 2

🔌 MCP: joining hands with the agent

Without MCP, your agent can only see what's inside the folder where it's running. With MCP, it can reach the outside world— websites, spreadsheets, email, databases—and you don't configure any API calls by hand: it reads the available tools and chooses which one to use on its own. This track takes you from the concept to a real build: turning a public website into a structured CSV, then running several MCP agents at the same time.

Caption: without MCP, the agent only sees the local folder. With MCP, it connects to a “standardized outlet” and reaches websites, spreadsheets, email, and databases—choosing the right tool on its own based on your request in Portuguese.
